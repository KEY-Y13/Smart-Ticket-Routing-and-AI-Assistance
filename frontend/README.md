# 前端状态

Vue 3 + Vite + Element Plus 前端已实现并连接真实业务接口，包含客户工单、客服工作台、管理员派单与 SLA、知识库、数据评审和实验报表。AI 复核与人工复核在界面中明确区分，草稿审核与发送为两个独立动作。

本地开发：在本目录执行 `npm ci`、`npm run dev`；构建执行 `npm run build`。`dist/` 为交付时构建产物，后端可提供该页面；修改源码后需重新构建。浏览器用例位于 `e2e/`，运行前按项目根 README 启动服务。

账号密码由本地初始化生成并保存在项目私有目录，不随 GitHub 仓库发布。完整业务流程与验收范围见项目根 README 和 `docs/23-本轮数据与业务评审交付.md`。
