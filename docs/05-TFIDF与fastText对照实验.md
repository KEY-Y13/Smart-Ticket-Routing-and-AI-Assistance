# 传统分类实验：TF-IDF 与 fastText 流程验证

## 入口和状态

`nlp/baselines/train.py` 为真实 sklearn 训练与评估；`nlp/fasttext/train.py` 调用隔离原生 worker；`nlp/evaluation/metrics.py` 计算统一指标。当前已实现三种要求模型及 LR 的 smoke 对照，正式数据实验仍未完成。

运行 `scripts\run_smoke.cmd` 使用新目录保存本次 CPU 实验。72 条未复核合成文本仅检查链路，不是正式业务评测。完整数值以 `artifacts/runs/<run>/comparison.json` 为准。

## TF-IDF 与维度

当前使用中文字符 1–2 gram，避免隐含分词词典，最大 20,000 个特征。输入 B 条文本，输出 `[B,V]` 稀疏矩阵，V 是训练集实际词表大小。TF-IDF 将词项频率与文档逆频率组合；sklearn 平滑 IDF 为 `log((1+n)/(1+df))+1`，再做默认 L2 归一化。验证/测试只 transform，不 fit。

替代方案为 jieba 词级 n-gram 或更长字符 n-gram，需在相同切分上比较。字符方法容易受共享用词影响，缺少完整语序和复杂语义。

## RF 与 LR

RF 100 棵树、最大深度 30、类别平衡、固定种子和单 CPU worker；用树分裂准则训练，不使用 BERT 的反向传播损失。高维稀疏文本上可能不如线性模型高效，故保留 LR 对照。

LR 对 TF-IDF 向量做线性映射，多类条件下优化分类损失和正则项；sklearn 负责优化。配置写入每次 `config.json`。数据 → 训练词表 → 分类器 → 六类分数 `[B,6]`。

## 阈值与测试隔离

验证集对不同最大分数阈值计算接收准确率，选择达到目标经验准确率时覆盖率最大的阈值；若不存在就禁用自动接收。阈值不是正确率保证，当前目标默认 0.9 仅是开发配置。RF/LR 的分数均未校准，不能当作真实正确概率。

验证集选阈值后才在独立测试部分计算完整分类和接收子集指标。测试集不得用于改阈值。小样本中一条正确也可能满足目标，因此实际部署仍需独立审批和更充分验证。

## 产物与验证

模型+词表整体保存为 pipeline，避免预测预处理不一致。保存配置、数据/切分/标签哈希、依赖、混淆矩阵（行真值/列预测）、逐类 Precision/Recall/F1、Macro-F1、CSV 预测、错误案例和预热延迟。重载后预测与保存前一致才通过。

延迟包含单条 TF-IDF 与分类器，不包含 HTTP；单并发、预热后每条测试重复五次。内存与 GPU 峰值尚未测量；记录 `not_measured`，不能声称完成资源性能验收。

joblib 仅接受可信本地产物，哈希不是防恶意反序列化方案。smoke 产物不可部署，正式产物也默认未审批。

## fastText 实现、原理和边界

本机 WSL 无 g++/make，本轮未安装全局编译器，改为单独 `.venv-fasttext` 中的第三方 `fasttext-wheel==0.9.2`。它不是官方 Windows 支持承诺；官方 Linux 方案保留为备选。隔离 worker 使用 NumPy 1.26.4，避免旧包装器与 NumPy 2 的 copy=False 不兼容，不修改第三方源码或基础环境。

NFKC 归一化、清除空白后按字符分隔。训练和预测共用同一个 preprocess。输入 `__label__0 文 本`，字符/子词和 n-gram 特征哈希到词表与 bucket，向量表示 64 维，再映射六类。设定 wordNgrams=2、minn=2/maxn=4、bucket=50000、softmax loss、seed=42、thread=1，保存完整配置。该表示不能等同于 BERT 的上下文注意力。

读取同一 split manifest，训练仅使用 train；原生 predict(k=6) 的标签顺序可能变化，worker 逐个标签重排为 0..5。对原生微小 epsilon 导致的分数和偏差做明确的归一化，再使用统一阈值和评估函数。不能把 `model.test` 的 P@1/R@1 当成逐类 Precision/Recall 或 Macro-F1。

测试发现第三方原生 Windows IO 不能读取中文目录。保留中文输出路径的失败测试，通过项目内 ASCII 临时目录执行原生文件操作，Python 复制最终产物到目标路径；只清理本次受控临时目录。当前项目根目录本身必须为 ASCII，否则明确报错，不静默改路径。失败日志与 JUnit 保留。

`tests_ml/test_fasttext_bridge.py` 实际训练两次，验证相同种子下预测和模型哈希一致，并检查旧实验目录不被覆盖。该结论限当前库和平台，不承诺跨版本/跨平台逐位一致。

模型文件和 worker 的训练输入、原始分数、日志、重载验证均保存。工作集峰值包含原模型与重载模型共存的整个 worker 生命周期；不能把它当单模型稳定内存占用。
