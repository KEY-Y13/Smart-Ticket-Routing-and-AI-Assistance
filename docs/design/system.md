# 工作台视觉规范

概念图：workbench-concept.png。采用白色侧栏、浅冷灰画布、深蓝正文和青色主操作。
结构是224px侧栏、48px身份栏、标题与工具栏、工单表格和右侧详情，不使用营销首屏或虚构统计卡。

颜色：画布 #f5f7fa，面板 #fff，文字 #172b4d，次要文字 #667085，边框 #dce2e9，主色 #087f8c。
字体：Microsoft YaHei / PingFang SC / sans-serif，正文14px、说明12px、标题28px，行高1.55。
组件：6px圆角、1px边框、表格50px行高、导航48px；选中行淡青底与左侧2px青线。
图标使用Element Plus官方outline图标，18px，避免emoji。画面不依赖位图资产。

可见文案沿用概念：工单工作台、管理客户诉求，追踪每一次处理、知识库、SLA 管理、数据统计、系统配置、搜索工单、全部状态、刷新、新建工单、消息、AI 助手、业务记录、操作日志、回复客户、发送回复、待人工审核、知识依据、LLM 未启用、退出、虚拟业务演示。

功能必需延展：权限按角色显示，只有客户能创建工单；管理员入口提供分类/分配/优先级与状态操作。
数据、时间、计数均来自接口；概念样例行不是种子业务记录。空数据呈现空状态。
知识库、SLA、统计与配置沿用同一导航/表格/表单体系，低于1100px时详情置于表格下方，低于700px时侧栏变为顶部横向导航。
