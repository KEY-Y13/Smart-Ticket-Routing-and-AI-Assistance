## 实际遇到的问题与修复

1. 初次 Ruff 发现 9 处超长行，格式化后通过，未关闭规则。
2. 初次 pytest：47 passed，但出现 Starlette TestClient 使用 HTTPX 的弃用警告。改用 FastAPI 官方文档的 HTTPX AsyncClient + ASGITransport + AnyIO；未忽略警告、未安装陌生替代包。重跑仍为 47 passed、无警告。
3. Windows PowerShell 拒绝运行 `.ps1`，提示 running scripts is disabled。改为 `.cmd` 入口 + Python 编排，未更改系统执行策略。
4. 检查发现训练 CLI 在“目标目录预先存在但无报告”时可能写入 failure.json。修复为仅对本次新建目录写失败记录，增加测试确认用户已有文件不被改变。

官方异步测试依据：https://fastapi.tiangolo.com/advanced/async-tests/
