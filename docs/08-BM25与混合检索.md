# BM25、RRF 与索引一致性

入口：`rag/text.py`、`services/knowledge.py`、`rag/evaluate.py`。BM25保留术语/型号的词面匹配，BGE补充语义改写。中文采用固定字符bigram，英文数字串整体保留，避免外部分词词典漂移，但对单字和跨词边界有局限。

BM25词项贡献为 `IDF*tf*(k1+1)/(tf+k1*(1-b+b*dl/avgdl))`，k1=1.5、b=0.75，IDF做平滑。TF贡献饱和，dl/avgdl修正文档长度。两路各取最多30个候选；RRF累加 `1/(60+rank)`，用名次融合而不直接相加不同量纲的BM25/余弦分数。前20个融合候选交给重排，最终取5个有效证据。

document_key标识逻辑文档，revision不可变。审核与发布分开；立即生效版本替换旧版，未来版本让旧版持续到切换时间。有效区间为 `valid_from <= now < valid_until`。发布/退役生成持久化重建任务，有租约、令牌、尝试次数和延迟，最多重试3次后FAILED；管理员也可手动构建。

SQL是知识有效性的事实源。索引结果再次校验文档状态、有效期和切块哈希；旧政策退役后即使仍在文件中，也不能进入草稿。新知识重建前可能暂时召回不到，采用安全拒答。文件写完而DB提交失败时留下未激活generation，不当作成功。

评测为100条可回答、10条应拒答的AI编写演示样本，未独立复核。Recall@5按前5个不同文档召回比例计算；MRR@5取首个相关文档名次倒数。同文档多个chunk不重复计数；无答案误通过数另报，不混进有答案Recall分母。

Windows CPU实测Recall@5：BM25 0.97、纯向量1.00、混合0.99、重排0.99。并非混合必然更好：这批数据纯向量已召回全部正确文档，混合截断反而损失一例。逐条排名、错误和延迟见 `artifacts/evaluation/retrieval-demo.json`。运行 `python -m rag.evaluate` 会实际检索，不调用LLM。
